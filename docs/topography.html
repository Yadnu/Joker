Jokebox system topography

User ⇄ Joker ⇄ Librarian ⇄ Box → Viewer. Information moves both ways through the Box.

User

Listener + Query Slot
  • Speaks, laughs, interrupts
  • Browser mic + speaker
  • Query Slot on /viewer
⇄

1. The Joker

Voice loop, comedy, sets
  • Full-duplex voice: ElevenLabs Convai (OpenAI Realtime fallback)
  • Barge-in: cancel, ack, still file the bit
  • Sets with transitions, bomb recovery
  • Good + deliberate-bad generation
  • Asks Box: funniest in genre
  • joker/
⇄

2. The Librarian

Judgment layer
  • Suggests angles before generation
  • Assigns genre, creates categories
  • Scores the reaction 0-10
  • Metadata: topic, style, length, flags
  • Contract: interface.py v1.0
  • librarian/
⇄

3. The Box

Archive API, no inference
  • PUT /box/upsert creates path
  • Read by path, counts, funniest
  • GET /compliance live
  • Accounts + Bearer, one library
  • PostgreSQL, SQLAlchemy, Alembic
  • box/
→

4. The Viewer

Transparency layer
  • Navigable tree with counts
  • Violations marked on nodes
  • Joke detail + trace, one screen
  • JSON / CSV export
  • viewer/ Next.js
