One live joke, end to end

Librarian suggests angles→ Joker builds set→ Generate joke→ Voice delivers→ Capture reaction→ Score→ Classify→ PUT /box/upsert→ Score < 4: adapt set
Every step writes a trace row with a rationale.

Design rules

  • Hierarchy: Box > Cabinet > Drawer > File > Joke, more than one child at every level
  • Separation: Box stores, Librarian judges, Joker performs
  • Seam: Joker and Librarian talk only through interface.py
  • Traceability: every model call goes through record_step
  • Provenance: generated or curated, model, prompt, rationale

Engineering decisions

  • Concurrency: ON CONFLICT DO NOTHING plus unique constraints, one commit per upsert
  • Compliance: computed live, so it cannot go stale
  • Auth: account taken from bearer, not body, so attribution can't be spoofed
  • Voice: provider behind a VoiceSession interface; barge-in still files the bit
  • Known gaps: generate.py imports librarian.critique; classify writes File rows by SQL
